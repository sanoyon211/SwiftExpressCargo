## 📖 Project Overview

**Swift Express Cargo** is a responsive cargo and delivery service website designed to showcase company services, highlight delivery features, and provide a smooth user experience. The website includes clean sections for services, pricing, and contact information.

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Markup & Structure |
| CSS3 | Styling & Animations |
| JavaScript (ES6+) | Interactivity & DOM Manipulation |

---

## ✨ Key Features

- 📱 Fully **responsive** design for all screen sizes
- 🎨 Clean and modern UI/UX layout
- ⚡ Fast loading — no frameworks, pure vanilla code
- 🗂️ Organized sections: Hero, Services, Features, Contact
- 🔗 Smooth scrolling and interactive navigation

---

## 📦 Dependencies

This project uses **no external dependencies**. It runs entirely on:

- HTML5
- CSS3
- Vanilla JavaScript

## 🚀 Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/sanoyon211/Swift_express.git

# 2. Navigate into the project folder
cd Swift_express

# 3. Open in your browser
# Simply open index.html in any browser
# OR use Live Server extension in VS Code
```

> **Tip:** Install the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension in VS Code for the best development experience.
